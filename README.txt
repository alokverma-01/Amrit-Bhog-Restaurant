AMRIT BHOG — RESTAURANT WEBSITE 
===============================

Included:
- Responsive single-page restaurant website
- Dark yellow / warm cream visual identity
- Hero entrance animation + loading animation
- Scroll reveal animations
- Interactive menu filters
- Add-to-order cart
- WhatsApp order-request flow
- Call and Google Maps buttons
- Opening hours, reviews, story, gallery and contact sections
- Mobile navigation

IMPORTANT CLIENT HANDOVER NOTES
--------------------------------
This is a front-end demo. It does NOT have a server/database/payment gateway.
The "Order Now" flow sends an order request to the restaurant's listed phone number through WhatsApp.
